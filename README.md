# FORMATEXT-PRO

FORMATEXT-PRO é um aplicativo da web projetado para formatar e processar texto. Construído com Next.js e TypeScript, ele fornece uma interface amigável para várias operações de texto.

## Instalação

Para instalar as dependências do projeto, execute o seguinte comando:

```bash
npm install
```

## Executando Localmente

Para iniciar o servidor de desenvolvimento, execute:

```bash
npm run dev
```

O aplicativo estará disponível em [http://localhost:9003](http://localhost:9003).
