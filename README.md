'''# FORMATEXT-PRO

FORMATEXT-PRO é um aplicativo da web projetado para automatizar a formatação de documentos, convertendo arquivos `.docx` em PDFs estilizados com precisão. Construído com Next.js, TypeScript e Shadcn/UI, ele fornece uma interface amigável para upload, análise e personalização de documentos.

## Funcionalidades

- **Upload de Documentos**: Faça upload de arquivos `.docx` diretamente na aplicação.
- **Análise Estrutural**: O aplicativo analisa o documento em busca de inconsistências comuns, como parágrafos em caixa alta ou quebras de linha incorretas.
- **Configuração de Estilo**: Personalize a aparência do seu PDF com opções para:
  - Família e tamanho da fonte
  - Alinhamento do texto
  - Espaçamento entre parágrafos
  - Tamanho da página e margens
  - Geração automática de sumário
- **Geração de PDF**: Converta seu documento em um arquivo PDF com os estilos aplicados, pronto para download.

## Instalação

Para instalar as dependências do projeto, execute o seguinte comando:

```bash
npm install
```

## Executando Localmente

Para iniciar o servidor de desenvolvimento, execute:

```bash
npm run dev
```

O aplicativo estará disponível em [http://localhost:9003](http://localhost:9003).
'''
