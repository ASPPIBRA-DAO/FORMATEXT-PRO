# **App Name**: FormaText Pro Automation

## Core Features:

- Document Analysis: Analyzes .docx documents for structural and formatting inconsistencies.
- Style Application: Applies predefined or custom style rules (fonts, sizes, spacing, alignment) to the entire document.
- Table of Contents Generation: Automatically generates a table of contents based on identified titles and chapters.
- PDF Conversion: Converts .docx files into pixel-perfect PDF documents using a rendering engine and CSS themes.
- Layout Validation: LLM tool for suggesting automated layout adjustments based on content and formatting requirements, helping the user validate page size, and optimize margings and padding. It will use a reasoning based approach to determine the correct adjustment.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) for a professional and sophisticated feel.
- Background color: Light Lavender (#E6E6FA), a very pale tint of the primary hue, for a subtle, clean backdrop.
- Accent color: Violet (#8F00FF), for highlights and calls to action.
- Headline font: 'Literata' (serif) for a classic, readable style.
- Body font: 'Inter' (sans-serif) for clear and modern text.
- Use minimalist icons representing document types and formatting actions.
- Maintain a clean and structured layout with consistent margins and padding.
